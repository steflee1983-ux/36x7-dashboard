# 福建36选7彩票看盘分析工具

一个纯前端的福建体育彩票36选7看盘分析工具，无需后端，直接浏览器打开即可使用。

## 功能特性

### 1. 开奖历史
- 查看2026年所有开奖记录
- 自动高亮显示7个开奖号码

### 2. 号码频率统计
- 统计01-36每个号码的出现次数
- 颜色深浅表示频率高低（深色=高频，浅色=低频）

### 3. 冷热号分析
- 热号：最近频繁出现的号码
- 冷号：长时间未出现的号码
- 温号：处于中间状态的号码

### 4. 遗漏统计
- 显示每个号码当前遗漏期数
- 用颜色标记遗漏状态（红色=严重遗漏）

### 5. 走势图
- 直观显示每个号码的出球情况
- 用彩色球标记出现位置
- 期号列固定，方便对照查看

### 6. 综合统计
- 和值分布分析
- 奇偶比统计
- 大小比统计
- 三区分布分析

### 7. 模拟投注
- 手动选择7个号码进行模拟投注
- 机选功能快速生成随机号码
- 模拟开奖并显示中奖结果
- 保存投注历史记录

## 数据更新

- **手动输入**：点击"手动输入"按钮，输入新一期开奖数据
- **在线更新**：点击"在线检查更新"从网络获取最新开奖数据（需联网）
- **数据持久化**：使用 localStorage 保存用户添加的数据，关闭浏览器后不会丢失
- **恢复初始**：点击"恢复初始数据"清空用户数据，恢复为默认数据

## 使用方法

1. 下载以下三个文件到同一目录：
   - `fj36x7-dashboard.html` - 主页面
   - `fj36x7-data.js` - 开奖数据
   - `fj36x7-app.js` - 应用逻辑

2. 用浏览器打开 `fj36x7-dashboard.html` 即可使用

## 技术栈

- HTML5 + CSS3
- 原生 JavaScript（无框架依赖）
- Chart.js（可选，用于图表展示）
- localStorage（数据持久化）

## 数据结构

`fj36x7-data.js` 中定义开奖数据，格式如下：

```javascript
[
  ["2026001", "2026-01-01", [13, 14, 20, 21, 22, 27, 28]],
  ["2026002", "2026-01-03", [3, 7, 12, 18, 25, 30, 33]],
  // ...
]
```
